# 변경 기록

## v0.12.0 — 2026-10-28
- **암기: n회독** (가리는 방식 '핵심어만 / n회독')
  - 본문의 모든 단어(숫자 포함, 조사만 있는 말·접속사 등 제외)를 후보로, 회독마다 4묶음 중 하나를 가림. 4회독이면 모든 단어가 한 번씩, 5회독부터 새로 섞임
  - 회독 수는 노트마다 설정 테이블에 저장(`study.progress:<노트>`), n회독 ○ ✕는 복습 기록에 넣지 않음 (단어마다 기록하면 복습 목록이 넘침)
  - 굵게가 없는 `#암기` 노트·메모도 목록에 나옴 ("n회독용")
- **암기: 블록과 누적 쌓기**: `#`·`##` 제목 단위로 블록을 나눠 한 블록만 풀기, 처음 블록부터 하나씩 이어 붙이는 누적 쌓기 (단계도 노트마다 저장)
- 출처: 임관종합평가 대본 빈칸 아티팩트의 n회독·누적 쌓기 방식을 옮김

## v0.11.0 — 2026-10-28
- **노트 = 읽기 + 쓰기**
  - 노트 폴더 안의 `.md`·`.txt` 파일을 앱 안에서 편집하고 저장 (`Ctrl+S`, 다른 노트로 넘어갈 때도 저장). 다른 프로그램에서 먼저 바뀐 파일은 덮어쓰지 않고 알림 (수정 시각 비교, 임시 파일에 쓴 뒤 교체)
  - **새 노트**: 노트 폴더·하위 폴더를 골라 `.md` 생성 (이름이 겹치면 번호)
  - **마크다운으로 바꾸기 / 텍스트로 바꾸기**: 확장자만 `.txt` ↔ `.md`, 내용은 그대로. `.txt`는 쓴 그대로, `.md`는 서식으로 표시
  - `.txt` 노트도 목록·읽기에 포함
- **vault 설정을 노트 폴더 목록으로 합침**: 모든 폴더가 같은 노트 폴더. 기존 vault는 처음 켤 때 목록 맨 앞으로 옮기고, 암기 기록 키(`ob:` → `obx:<폴더>|`)도 함께 옮김
- "옵시디언에서 열기" 제거 → **폴더에서 보기**. `obsidian://` 열기 권한도 뺌
- **메모는 메모, 노트는 노트**: 메모 자동 저장(vault 사본) 제거. 메모 페이지의 **노트로 보내기**만 남김, 보낼 폴더는 노트 설정에서 고름 (`notes.memoDir`, 기존 설정은 `<vault>\Niagara`로 옮김)
- 화면 문구에서 옵시디언 언급 정리, 노트 아이콘을 보석 → 공책으로
- **백업 파일을 `.nia`로 저장**. 가져오기는 `.nia`·`.nora`(Nora 백업)·`.zip` 모두 가능 (형식은 같은 zip)
- **설치 파일을 GitHub Releases로 배포**: 버전 태그를 push하면 `setup.exe`를 릴리스에 바로 올림 (zip·로그인 없이 내려받기). main push마다 만드는 Actions 아티팩트는 그대로
- 테스트 보강 (Rust 63개)

## v0.10.0 — 2026-10-28
- 메모·노트 통합 1단계
  - **메모 자동 저장**: 메모를 고치거나 그룹을 옮길 때마다 vault의 메모 폴더(기본 `Niagara\`)에 `.md`로 함께 저장. 그룹 = 하위 폴더, 그룹을 옮기면 파일도 이동. 노트 폴더 설정에서 끌 수 있음. 저장 실패가 메모 저장을 막지 않음
  - **더 읽을 폴더 여러 개**: vault 말고도 폴더를 추가해 읽기 전용으로 함께 보기 (폴더 이름으로 묶임). 암기 대상에도 포함
  - 사이드바 '옵시디언' → **'노트'**
  - vault에 자동 저장된 메모 사본은 암기 목록에서 중복으로 나오지 않음
- 테스트 보강 (Rust 61개)

## v0.8.0 — 2026-10-28
- **암기 페이지 (인출 연습)** 추가
  - 대상: `#암기` 태그가 있는 옵시디언 노트와 Niagara 메모 (본문의 `#암기`·`#암기/과목` 또는 프런트매터 `tags`). 강조용 굵게만 있는 노트는 제외
  - 목록: 폴더(메모는 그룹)별로 접고 펼치기, 폴더 안에서는 오늘 복습·약점이 많은 순
  - 굵게 쓴 부분이 빈칸 → 떠올리고 펼친 뒤 ○/✕ 자기 채점. 키보드 Space·1·2, 채점하면 다음 빈칸으로 이동
  - 모드: 전체 / 오늘 복습 / 약점. 약점 = 마지막이 ✕이거나 ✕가 ○보다 많은 빈칸
  - 기록과 복습 간격(`cloze.rs`): 빈칸마다 ○/✕ 횟수, 상자 1~5 (1·2·4·8·16일), ✕는 다음 날 다시
  - 태그는 노트 파일 안에만 있고 Niagara는 ○/✕ 기록만 저장
- **가벼움 최적화**
  - 일본어 글꼴(Noto Sans JP) 번들 제거, 일본어는 시스템 글꼴 → 화면 파일 9.8MB → 4.6MB
  - 한눈에 보기 외의 페이지는 처음 열 때 불러옴 → 시작 시 코드 약 40%
- **꾸미기**를 사이드바에서 설정 화면으로 이동
- 옵시디언 문법 스타일(콜아웃·링크·첨부·하이라이트)을 공용 스타일로 옮김
- 알파 테스트용 정적 미리보기 빌드 `npm run preview:build` (예시 데이터)
- 테스트 4개 추가 (Rust 60개)

## v0.7.0 — 2026-10-28
- **저장 구조 개편** (`storage.rs`): 한 기준 폴더 아래를 용도별로 나눔
  - `data\` 앱 내부용 (DB, 이미지) · `brief\` 바깥 도구용 (`brief.json`, `brief.schema.json`)
  - Windows 릴리스 빌드는 설치 폴더를 기준으로 씀 (쓰기 가능할 때). 언인스톨러는 자기가 설치한 파일만 지우므로 두 폴더는 삭제·업데이트에도 남음
  - 설치 폴더에 쓸 수 없으면 앱 데이터 폴더(`%APPDATA%\com.niagara.scheduler`) 사용. 이미 데이터가 있는 쪽을 항상 우선해 위치가 바뀌지 않음. 0.6 이하의 루트 DB도 그 자리에서 계속 사용
- **`brief.schema.json`**: 브리프 구조 설명(JSON Schema, 필드 뜻은 한국어)을 따로 저장. 테스트로 실제 출력과 일치를 보장
- 설정의 "모닝 브리프 파일" 카드를 **"저장 위치"** 카드로 확장: 앱 데이터, 모닝 브리프, 옵시디언 노트 폴더, 보낸 메모 폴더를 한곳에서 보고 폴더 열기
- 구글 드라이브 복사본 경로는 넣지 않기로 함
- 테스트 6개 추가 (Rust 56개)
