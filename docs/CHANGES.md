## v0.13.0 — 2026-10-29
- **일정 가져오기 (.ics)**: 설정 → 내 데이터 → 일정 가져오기. `.ics` 파일이나 구글 캘린더 전체 내보내기 `.zip`을 읽음 (네트워크 없음, 파일만)
  - 가져오기 전에 미리보기: 캘린더 이름, 일정·반복 개수, 이미 가져온 것, 지난 일정, 옮길 수 없는 반복 규칙 수
  - 지난 일정은 기본으로 빼고, 켜면 함께 가져옴
  - 반복: FREQ·INTERVAL·주간 BYDAY·UNTIL·COUNT·EXDATE, 옮겨진 회차(RECURRENCE-ID)는 시리즈에서 빼고 따로 넣음. "매달 둘째 화요일" 같은 규칙은 첫 날짜만 넣고 개수를 알려 줌
  - UID로 기억해서(`ics_imports` 테이블) 같은 파일을 다시 가져오면 겹치지 않고 갱신. Niagara에서 바꾼 색·태그·알림은 유지, Niagara에서 지운 일정은 되살리지 않음
  - 시간: `Z`(UTC)는 이 컴퓨터 시간대로 바꾸고, TZID가 붙은 시간은 그대로 읽음
- **설정 정리**
  - 기능 타일을 끌어다 놓아 사이드바 순서 변경 (Alt + ←/→도 됨). 접혀 있던 순서 목록과 화살표는 뺌
  - "정보 / 시작 안내 다시 보기"를 위험 구역 위로
  - **위험 구역**은 접었다 펴는 카드로, 백업 가져오기(현재 데이터 대체)와 모든 데이터 삭제를 여기로 모음
- 테스트 보강 (Rust 66개)

## v0.11.0 — 2026-10-28
- **노트 = 읽기 + 쓰기**
  - 노트 폴더 안의 `.md`·`.txt` 파일을 앱 안에서 편집하고 저장 (`Ctrl+S`, 다른 노트로 넘어갈 때도 저장). 다른 프로그램에서 먼저 바뀐 파일은 덮어쓰지 않고 알림 (수정 시각 비교, 임시 파일에 쓴 뒤 교체)
  - **새 노트**: 노트 폴더·하위 폴더를 골라 `.md` 생성 (이름이 겹치면 번호)
  - **마크다운으로 바꾸기 / 텍스트로 바꾸기**: 확장자만 `.txt` ↔ `.md`, 내용은 그대로. `.txt`는 쓴 그대로, `.md`는 서식으로 표시
  - `.txt` 노트도 목록·읽기에 포함
- **vault 설정을 노트 폴더 목록으로 합침**: 모든 폴더가 같은 노트 폴더. 기존 vault는 처음 켤 때 목록 맨 앞으로 옮기고, 암기 기록 키(`ob:` → `obx:<폴더>|`)도 함께 옮김
- "옵시디언에서 열기" 제거 → **폴더에서 보기**. `obsidian://` 열기 권한도 뺌
- **메모는 메모, 노트는 노트**: 메모 자동 저장(vault 사본) 제거. 메모 페이지의 **노트로 보내기**만 남김, 보낼 폴더는 노트 설정에서 고름 (`notes.memoDir`, 기존 설정은 `<vault>\Niagara`로 옮김)
- 화면 문구에서 옵시디언 언급 정리, 노트 아이콘을 보석 → 공책으로
- **백업 파일을 `.nia`로 저장**. 가져오기는 `.nia`·`.nora`(Nora 백업)·`.zip` 모두 가능 (형식은 같은 zip)
- **설치 파일을 GitHub Releases로 배포**: 버전 태그를 push하면 `setup.exe`를 릴리스에 바로 올림 (zip·로그인 없이 내려받기). main push마다 만드는 Actions 아티팩트는 그대로
- 테스트 보강 (Rust 63개)
